Como resolver (PostgreSQL local)

  1. Verifique se o serviço do PostgreSQL está rodando. No Windows, abra Serviços e inicie postgresql-x64-XX.
  2. Confira que o banco mercado_pro existe: psql -U postgres -c "\l". Se não aparecer, rode CREATE DATABASE mercado_pro;.
  3. Confira que as tabelas foram criadas: psql -U postgres -d mercado_pro -c "\dt". Devem aparecer: clientes, produtos, vendas, itens_venda.
  4. Confira o arquivo .env. O formato deve ser: DATABASE_URL=postgresql://postgres:SUA_SENHA@localhost:5432/mercado_pro.
  5. Pare o Flask (Ctrl+C) e rode novamente python src/app.py.

Para checar rapidamente, rode: python src/testar_conexao.py
